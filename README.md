# Hebrew Video Skills

שני סקילים נפרדים לעריכת וידאו בעברית. בוחרים לפי התוצאה המבוקשת, לא לפי אורך הסרטון בלבד.

| בקשה | סקיל | מה נשמר |
| --- | --- | --- |
| סרטון קצר לפרסום מתוך ראיון, עדות או חומר גלם | [`hebrew-promo-video-editor`](skills/hebrew-promo-video-editor/SKILL.md) | בחירת מסר, חיתוך מדויק, פתיח וסיום מכוונים, מיתוג וכתוביות |
| תמלול, תרגום וכתוביות לסרטון קיים | [`hebrew-subtitle-translator`](skills/hebrew-subtitle-translator/SKILL.md) | סדר הדברים, הדוברים והסרטון המלא, אלא אם התבקש קיצור במפורש |

אם נדרש **סרטון פרסומי מתורגם**, משתמשים בשני המסלולים ברצף: בוחרים את הקטעים לפי מסלול הפרסום, ואז מתמללים ומתרגמים את הגרסה שנבחרה. טקסט פרסומי חדש מוצג כגרפיקה נפרדת; הוא אינו מתחזה לדברי המרואיין.

## עקרונות שנלמדו מהעבודה

- בסרטון פרסומי בוחרים קטעים שמובנים גם לצופה שלא שמע את הראיון: פתיח מסקרן, זיהוי הפרויקט, יתרון קונקרטי, הוכחה או אמינות, ומשפט סיום שלם. לא חייבים לכפות את כל המרכיבים על כל סרטון.
- לא פותחים בפריים מטושטש או בפריים מעבר, ולא מסיימים בפריים אקראי. בודקים בפועל את הפריים הראשון, האחרון ואת סיום המשפט הנשמע.
- חומר פרסום חיצוני יכול לשמש פתיח, סגיר או רקע חזותי; קול של דובר אחר לא נכנס באמצע המסר בלי החלטה מפורשת.
- כתוביות תרגום הן תרגום נאמן לדיבור, לא ניסוח שיווקי. מתמללים את האודיו המקורי; כתוביות פלטפורמה הן לכל היותר כלי עזר לבדיקת שמות.
- בראיון ארוך מעדיפים כתוביות לבנות ונקיות בסגנון תיעודי, בפונט עברי קריא, בתחתית הפריים וללא הסתרת פנים. בסרטון קצר אפשר להשתמש בטיפול מודגש יותר של Sofit, תוך שמירה על אזורי הבטיחות של הפלטפורמה.
- תמלול לא ודאי, במיוחד ביידיש או בהקלטה דחוסה, אינו בסיס לתרגום מומצא. עוצרים, מסמנים אי־ודאות או מבקשים מקור טוב יותר.

## התקנה

העתיקו את שתי התיקיות שבתוך `skills/` אל תיקיית הסקילים של Codex. כל תיקייה היא סקיל עצמאי. מסלול הפרסום כולל עזרי עבודה עם [Sofit](https://github.com/navotvolkgroundup/sofit); מסלול הכתוביות יכול להשתמש ב[צינור התמלול והתרגום המשולב](https://github.com/mnigli/sofit-luna-video). סביבת ריצה, מודלים, קובצי מדיה ותוצרים אינם כלולים במאגר הזה.

```powershell
git clone https://github.com/mnigli/hebrew-video-skills.git
Copy-Item -LiteralPath .\hebrew-video-skills\skills\hebrew-promo-video-editor -Destination "$env:USERPROFILE\.codex\skills" -Recurse
Copy-Item -LiteralPath .\hebrew-video-skills\skills\hebrew-subtitle-translator -Destination "$env:USERPROFILE\.codex\skills" -Recurse
```

בעת עדכון סקיל שכבר מותקן, סנכרנו את הקבצים לאחר בדיקת השינויים במקום להניח שהעתקה חוזרת תחליף את הגרסה הקיימת.
